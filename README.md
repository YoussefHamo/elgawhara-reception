# مجموعة الجوهرة لطب الأسنان - فرع ميامي
## بوابة ونظام إدارة الاستقبال الموحد (Al-Jawhara Dental Reception System)

نظام إلكتروني متكامل وعالي الأداء لإدارة شؤون الاستقبال والعيادات وحساب تكلفة العلاج لفرع ميامي - الإسكندرية.

---

### ✨ المميزات الرئيسية للنظام:
1. **استعلام فوري لمواعيد الأطباء (61 طبيب مسجل):**
   - محرك بحث عربي ذكي لحظي وسريع جداً.
   - فلترة حسب التخصصات (أطفال Pedo، جراحة، تقويم، زراعة وغرس، تركيبات، عام وجذور).
   - عرض فترات الحضور الصباحية والمسائية وأرقام العيادات.

2. **توزيع العيادات اللحظي المباشر (Live Floor Map):**
   - خريطة تفاعلية لتواجد الأطباء في العيادات من 1 إلى 16 بالإضافة لعيادات الأطفال وأشعة البانوراما.
   - مؤشرات فورية للعيادات المشغولة والشاغرة والاعتذارات اليومية.

3. **جدول الشيفتات الأسبوعي الشامل (Weekly Matrix):**
   - مصفوفة أسبوعية متكاملة لجميع أيام الأسبوع والشيفت الصباحي والمسائي.
   - عمود اليوم مثبت مع شادو ناعم لتصفح مريح على الشاشات اللمسية والموبايل.

4. **قائمة الأسعار والخدمات الطبية (171 إجراء طبي):**
   - تصنيف كامل حسب أقسام طب الأسنان.
   - دعم أسعار الأخصائي والاستشاري.
   - زر نسخ فوري للأسعار وإضافة مباشرة للحاسبة.

5. **حاسبة تكلفة العلاج وعروض الأسعار (Treatment Calculator):**
   - اختيار وتجميع خطط العلاج وحساب المجموع والخصم تلقائياً.
   - تجهيز عروض الأسعار بنقرة زر للمشاركة عبر الواتساب أو الطباعة المباشرة.

6. **سبورة التعليمات والملاحظات الإدارية:**
   - توجيهات لحظية لموظفي الاستقبال، التنبيه على صيانة الأجهزة ومستجدات الشفتات.

7. **لوحة تحكم إدارية شاملة ومحمية برمز أمني (Admin Portal):**
   - صلاحيات كاملة للمدير لإضافة وتعديل الأطباء والأسعار والملاحظات وتسجيل الاعتذارات.
   - استعادة البيانات الافتراضية بنظام التحقق المزدوج للرمز السري.

8. **التشغيل بدون إنترنت والتوافق الشامل (PWA & Offline-First):**
   - مجهز كـ Progressive Web App (PWA) يعمل تلقائياً عند انقطاع الإنترنت.
   - تصميم متجاوب فائق النعومة (60/120 FPS) مخصص لجميع الشاشات (الكمبيوتر، اللابتوب، الآيباد والتابلت، والموبايل).
   - الوضع النهاري المريح للعين افتراضياً مع خيار التبديل للوضع الليلي.

---

### 🛠️ التقنيات المستخدمة:
- **Frontend:** Vanilla JavaScript (ES6+), Tailwind CSS CDN, Cairo Typography.
- **Icons:** Inline Vector SVGs & Lucide Icons.
- **Backend & Cloud Database:** Supabase Realtime Database.
- **Hosting:** Vercel Production Infrastructure.
- **Offline Engine:** Service Worker API & Cache Storage.
